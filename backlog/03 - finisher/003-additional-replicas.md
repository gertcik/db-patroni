# 003 — Дополнительные реплики PostgreSQL 18

Добавить 2 экземпляра PostgreSQL 18 в существующий docker-compose.yml кластера Patroni:

1. **Физическая реплика** (streaming replication) через HAProxy
2. **Логическая реплика** (logical replication) таблиц `shop.*`

## Требования

### Общие
- Оба экземпляра в `patroni-cluster/docker-compose.yml`
- Каждый на своём Docker volume для данных
- Пароль суперпользователя: `secret` (как в кластере)
- Версия PostgreSQL: 17 (образ `postgres:18`)

### Физическая реплика (через HAProxy)
- `primary_conninfo` указывает на `haproxy:5432`, пользователь `replicator`
- Реплика следует за мастером кластера через HAProxy (автоматически после failover)
- Read-only, streaming replication (WAL)
- Проверить работу после failover мастера

### Логическая реплика
- Публикация на мастере кластера для `shop.users`, `shop.products`, `shop.orders`
- Подписка на логическую реплику с этих таблиц
- Возможность читать данные через логическую реплику
- `wal_level=logical` уже включён в конфиге Patroni кластера

## Конфигурация

### docker-compose.yml
Добавить 2 сервиса:
- `pg-physical-replica` — образ `postgres:18`, настроенный как горячая standby через `primary_conninfo`
- `pg-logical-replica` — образ `postgres:18`, настроенный с логической подпиской (CREATE SUBSCRIPTION)

### HAProxy
Текущая конфигурация HAProxy должна пропускать replication-трафик на мастер (проверить).

### Инициализация
- При первом запуске физическая реплика: `pg_basebackup` через HAProxy
- При первом запуске логическая реплика: создать publication на мастере, subscription на реплике

## Порты (хост)
- Физическая реплика: 5433
- Логическая реплика: 5434

## Проверка
- Данные shop доступны на обоих репликах
- После insert на мастере данные появляются на репликах
- После остановки мастера Patroni физическая реплика переключается на новый мастер через HAProxy
- Логическая реплика продолжает получать изменения от нового мастера (публикация сохраняется)

## Зависимости
- HAProxy настроен на replication-трафик
- Patroni кластер работает (задача #002)
