# Backlog — управление задачами

## Структура каталогов

```
backlog/
├── 01 - wait/       # задачи ожидают начала работы
├── 02 - work/       # задачи в процессе выполнения
├── 03 - done/   # завершённые задачи
└── README.md
```

## Как работать

### Создать задачу
Создай файл `.md` в `01 - wait/` с уникальным номером: `NNN-kratkoe-opisanie.md`. Номер увеличивается относительно последнего.

### Начать работу над задачей
Перемести файл из `01 - wait/` в `02 - work/` (номер и имя не меняются):
```
Move-Item "backlog/01 - wait/002-task.md" "backlog/02 - work/002-task.md"
```

### Завершить задачу
Перемести файл из `02 - work/` в `03 - done/`:
```
Move-Item "backlog/02 - work/002-task.md" "backlog/03 - done/002-task.md"
```

### Просмотр задач по статусу
```powershell
# все ожидающие задачи
Get-ChildItem "backlog/01 - wait/*.md" | Sort-Object Name

# задачи в работе
Get-ChildItem "backlog/02 - work/*.md" | Sort-Object Name

# завершённые
Get-ChildItem "backlog/03 - done/*.md" | Sort-Object Name
```

## Структура файла задачи (.md)

Каждый файл задачи содержит frontmatter-поля и секции:

```markdown
# Название задачи

**Статус:** wait | work | done
**Приоритет:** high | medium | low
**Создана:** ГГГГ-ММ-ДД
**Дедлайн:** ГГГГ-ММ-ДД (опционально)

## Описание
Что нужно сделать.

## Критерии готовности (DoD)
- [ ] условие 1
- [ ] условие 2

## Шаги выполнения
1. шаг
2. шаг

## Заметки
Ссылки, контекст, уточнения.
```

Поля **Статус**, **Приоритет**, **Создана** позволяют быстро фильтровать и сортировать задачи. Чекбоксы в **DoD** — для отслеживания прогресса.
